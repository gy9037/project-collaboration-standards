# 决策记录

## 用途

落实规范第 1 条中「重要决定的原因以 Decision Record 为准」。让后来的人和 AI 不翻聊天记录也能知道为什么这样决定、考虑过什么、何时被替代。

## 触发场景

满足任一条即写 DR：

- 以后有人会问「为什么这样做」，且答案不在代码或 PROJECT.md 里；
- 在两个以上可行方案中做了取舍，没选的方案以后可能被再次提出；
- 决定改变了项目的约束、架构、数据结构、对外接口、所用平台或工作方式；
- 推翻或修改了一份已有 DR。

不触发：

- 普通实现细节（变量命名、函数拆分、样式微调）；
- 只影响当前 Issue、合并后就无人关心的选择，写在 Issue / PR 里即可；
- 纯状态变化（阶段、进度），写在 PROJECT.md 或 Issue。

## 步骤

1. **判断是否需要 DR。** 对照上方触发场景。拿不准时问自己：半年后换一个执行者，没有这份记录会不会做出相反的决定或重新讨论一遍？会就写。
2. **确定编号和路径。** 项目中路径为 `docs/decisions/DR-NNN-<标题>.md`（规范仓库自身为 `standards/decisions/`）。目录不存在时此时才创建。列出已有文件，取最大编号加 1，三位数补零（DR-001、DR-002…）。标题用简短中文或小写连字符英文，描述决定本身，例如 `DR-004-改用SQLite存储`。
3. **按 `optional-templates/decision.md` 填写。** 字段全部填写，没有内容的写「无」：
   - 状态、日期（YYYY-MM-DD）；
   - 背景：当时面对什么问题、有哪些约束；
   - 决定：一句话能说清的结论；
   - 原因：为什么选它，依据什么证据；
   - 影响：改变了什么、带来哪些代价或后续工作；
   - 备选方案：考虑过但没选的方案，各自没选的原因；
   - 替代关系：替代了哪份 DR / 被哪份替代，没有写「无」。
4. **决策点：设定状态。**
   - 决定需要用户取舍，或属于规范第 6 条审批事项、修改正式规范：写 `Proposed`，在 Issue / PR 中请用户确认；确认后改为 `Accepted`，并在 DR 中记录确认日期和确认位置（Issue / PR 链接）。
   - 决定在 AI 可自行处理的范围内：直接写 `Accepted`，在 Issue / PR 中汇报。
   - 决定不再适用、也没有新决定接替：改为 `Deprecated`，在「替代关系」写明原因和日期。
5. **决策点：替代旧决定。** 不修改旧 DR 的背景、决定、原因等正文。
   - 新建一份 DR，「替代关系」写「替代 DR-NNN」；
   - 旧 DR 只改两处：状态改为 `Superseded`，「替代关系」追加「被 DR-MMM 替代（日期）」。
6. **随任务分支提交**，在 Issue / PR 中链接该 DR。决定改变了 PROJECT.md 中的关键约束或重要入口时，同一 PR 内同步更新 PROJECT.md。

## 示例

项目原先用 JSON 文件存数据（DR-002，Accepted），现在数据量增长，AI 评估后建议改用 SQLite，涉及 Critical Areas 中的数据存储。

1. 符合触发场景（改变数据结构、推翻已有 DR）。
2. `docs/decisions/` 下最大编号为 DR-003，新建 `DR-004-改用SQLite存储.md`。
3. 填写：背景为 JSON 文件读写在 5 万条后明显变慢；决定为改用 SQLite；原因附基准测试结果；影响为需写迁移脚本、备份旧数据；备选方案为「继续用 JSON 并分片（复杂度高，未选）」「上云数据库（产生费用，未选）」；替代关系「替代 DR-002」。
4. 涉及数据结构变更，状态写 `Proposed`，在 Issue 中请用户确认。用户确认后改为 `Accepted`，写入确认的 Issue 链接。
5. DR-002 状态改为 `Superseded`，替代关系追加「被 DR-004 替代（2026-11-25）」，正文不动。
6. 同一 PR 更新 PROJECT.md 关键约束中的存储方式。

## 验收

- [ ] 决定符合触发场景，不是普通实现细节
- [ ] 文件名为 `DR-NNN-<标题>.md`，编号连续、未与已有编号重复
- [ ] 模板字段全部填写，「备选方案」列出未选方案及原因
- [ ] 状态与第 4 步一致；`Proposed` 的 DR 已在 Issue / PR 中请用户确认
- [ ] 替代时新建了 DR，旧 DR 只改状态和替代关系，正文未改
- [ ] Issue / PR 中有 DR 链接；涉及 PROJECT.md 的内容已同步
