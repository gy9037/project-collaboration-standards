# 按需模板

这些文件是备用样板，不需要全部复制进项目。

- 重要决定：复制 decision.md 到 docs/decisions/DR-001-标题.md。
- 特殊复杂交接：复制 handoff.md 到 docs/handoff/；日常交接在当前 Issue 评论中使用同样字段。
- 合并确认：将 merge-confirmation.md 内容发给用户并保存到 PR。
- 流程反馈 / 每周蒸馏：使用 feedback.md / weekly-distillation.md。
- 研究、架构、测试、部署：有实际需求时复制对应样板，文件路径由项目记录。
- 平台迁移：使用 migration.md 核对 Git 以外的协作历史。
