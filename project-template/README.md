## 模板接入说明（填写后可删除）

复制整个目录，填写三个核心文件，保留 `.standards/v1.0/STANDARD.md`。`.github/` 是可选平台适配；非 GitHub 项目将其字段迁到实际平台，可移除该目录。

`code` 在实际需要时增加源码、构建与测试入口；`non-code` 增加交付物及验收方式；`hybrid` 同时覆盖两种成果。无需提前创建大量空目录。

先完成项目内 [接入清单](.standards/ADOPTION.md) 的“执行前准备”，再开展首个受控任务；该任务按正常流程验收并经用户确认合并后，才标记“接入验收完成”。本目录为模板，不代表已完成立项、已配置 main 保护或通过项目验收。
