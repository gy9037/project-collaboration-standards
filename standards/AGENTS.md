# 规范仓库执行规则

Standard Version: v1.0

先读 README.md、MAINTAINER.md、README.md 指向的当前正式版本和当前 Issue/PR。以版本文件为规范事实源。此仓库当前采用 v1.0；版本升级时同步此文件的 Standard Version 和 README 当前版本入口，不自动改动使用该规范的旧项目。

收集反馈与提出建议可直接执行；修改正式规则和升级版本需要用户确认。发布版本保留历史，新版本另建目录；项目继续执行自己锁定版本。

分支执行并验证引用、模板与规则一致性，记录独立审查结果及未验证项；PR 附用户确认卡，经用户确认才合并 main。默认 Squash Merge。

Overrides：无。
