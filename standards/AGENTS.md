# 规范仓库执行规则

Standard Version: v2.0

先读 README.md、当前正式版本 [v2.0](versions/v2.0/STANDARD.md) 和当前 Issue/PR，以版本文件为规范事实源。场景匹配时按规范第 10 条触发表使用 skill；维护规范和 skill 按 collab-standard-maintenance 执行。

修改正式规范、发布新版本、改变 skill 的步骤或判定条件，按规范第 9 条经用户确认（第二档）。新版本另建目录，已发布版本不改；版本升级时同步此文件和 README 当前版本入口，不自动改动使用该规范的项目。

Overrides：无。
