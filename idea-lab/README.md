# Idea Lab

想法先探索再立项。初次复制 [想法模板](templates/idea.md) 到 `ideas/inbox/<日期>-<名称>.md`，仅填标题、原始想法、日期。

目录位置代表状态：Inbox → Exploring → Validating → Ready；另有 Parked / Dropped。移动文件时保留历史；每个想法只在一个状态目录中存在。其余目录在首次使用时创建。

逐步补充问题、对象、价值、假设与证据、可行性、成本、风险、依赖、机会成本、最小验证和退出条件。未验证内容标为“假设 / 待验证”。

Ready 至少满足：问题基本明确、关键可行性已判断、关键假设已识别、值得投入、第一阶段目标明确、范围和暂不做内容明确、可执行第一步已知。

立项后保留原 Idea，添加正式仓库链接及日期；Ready 不等于项目任务已完成。

采用 [v1.0 规范快照](.standards/v1.0/STANDARD.md)，不用评分系统或自动初始化流程。
